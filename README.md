# image-to-prompt

ImageToPrompt — Chrome 扩展，右键任意图片或按 Alt+Q 触发，调用多模态 AI 反推图片提示词。支持抖音等现代网站的动态图片。

## 功能

- 右键菜单触发 / Alt+Q 快捷键
- 自动探测页面中的图片（含懒加载）
- 输出可直接用于 Midjourney / Stable Diffusion 的英文 Prompt

## 配置

扩展选项页中填入 OpenAI 兼容 API 的 Base URL 和 API Key。

## 安装

1. 打开 `chrome://extensions/`
2. 开启「开发者模式」
3. 「加载已解压的扩展程序」→ 选择此目录
